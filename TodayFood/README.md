# 🍱 나의 식단표

한 주의 아침·점심·저녁·간식을 미리 계획하는 개인용 식단표 웹 앱입니다.
칸을 눌러 메뉴를 여러 개 넣고, 자주 먹는 메뉴는 즐겨찾기로 저장해 빠르게 추가할 수 있어요.
메뉴마다 재료를 적어 두면 그 주의 **장 볼 목록**을 중복 없이 모아 주고, 체크하면서 장을 볼 수 있습니다.
주간·월간 보기, 지난주 식단 불러오기, 끼니·하루 복사, 메모 앱용 텍스트 복사, 라이트/다크 모드, 백업·복원을 지원합니다.
서버 없이 동작하며, 데이터는 **내 기기의 브라우저에만** 저장됩니다.

---

## 1. GitHub Pages로 배포하기

> PC에서 하는 것을 권장해요. 휴대폰 웹에서는 `icons` 폴더째 올리기가 어렵습니다.

1. **저장소 만들기**
   - [github.com](https://github.com) 로그인 → 오른쪽 위 **+** → **New repository**
   - Repository name 예: `meal-planner`
   - **Public**(공개) 선택 → **Create repository**
2. **파일 올리기**
   - 만든 저장소 화면에서 **Add file > Upload files**
   - 이 폴더 안의 내용을 **그대로** 끌어다 놓기
     (`index.html`, `manifest.webmanifest`, `sw.js`, `README.md`, `.nojekyll`, `icons` 폴더)
   - `icons` 폴더는 폴더째 끌어다 놓아야 경로가 유지돼요.
   - `.nojekyll`은 이름이 점(.)으로 시작해서 파일 탐색기에서 숨겨져 있을 수 있어요.
     안 보이면 저장소에서 **Add file > Create new file**로 이름만 `.nojekyll`로 만들고 내용은 비워 둔 채 저장하세요.
   - 아래 **Commit changes** 버튼 클릭
3. **Pages 켜기**
   - 저장소 **Settings > Pages**
   - **Build and deployment**의 Source는 **Deploy from a branch**
   - **Branch**를 `main`, 폴더를 `/ (root)`로 고르고 **Save**
4. **접속 주소 확인**
   - 같은 화면 위쪽에 `https://사용자명.github.io/meal-planner/` 같은 주소가 나타나요.
   - 배포 후 실제로 반영되기까지 **1~2분** 걸릴 수 있어요. 안 열리면 잠시 후 새로고침하세요.

**공개 저장소에 대한 안내**
무료 계정은 저장소가 **공개(public)** 여야 Pages를 쓸 수 있어요.
공개되는 것은 **앱의 코드뿐**이고, 내가 입력한 식단 데이터는 내 기기 브라우저에만 저장되므로 공개되지 않아요.

---

## 2. 휴대폰에서 앱처럼 쓰기

- **안드로이드(크롬)**: 접속 주소를 연 뒤 오른쪽 위 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**
- **아이폰(사파리)**: 접속 주소를 연 뒤 아래 **공유 버튼**(□↑) → **홈 화면에 추가**

홈 화면 아이콘으로 열면 주소창 없이 앱처럼 열리고, 한 번 열어 둔 뒤에는 인터넷이 없어도 열려요.

---

## 3. 주의사항

- **데이터는 사용한 기기·브라우저에만 저장돼요.** 다른 기기나 다른 브라우저와 자동으로 공유되지 않아요.
- 브라우저의 **사이트 데이터(쿠키·저장공간)를 지우면 식단 기록도 삭제**돼요.
  **설정(⚙️) > 데이터 내보내기**로 백업 파일을 저장해 두고, 필요할 때 **데이터 불러오기**로 복원하세요.
  기기를 바꿀 때도 같은 방법으로 옮길 수 있어요.
- **파일을 수정해서 다시 올렸는데 반영이 안 되면** `sw.js` 맨 위의 캐시 버전을 올려 주세요.
  ```js
  const CACHE_VERSION = 'meal-planner-v2';  // → 'meal-planner-v3'
  ```
  올린 뒤 앱을 한두 번 새로 열면 새 버전이 적용돼요.
- **아이콘을 바꿔도** 홈 화면에 이미 추가한 앱 아이콘은 바로 바뀌지 않을 수 있어요.
  홈 화면에서 **삭제 후 다시 추가**하세요.

## 파일 구성

```
├─ index.html            앱 본체 (HTML·CSS·JS)
├─ manifest.webmanifest  PWA 설정 (앱 이름, 아이콘, 색상)
├─ sw.js                 서비스 워커 (오프라인 캐시)
├─ icons/                앱 아이콘 (192, 512, 마스커블 512, iOS 180, favicon.svg)
├─ .nojekyll             GitHub Pages의 Jekyll 처리 방지용 빈 파일
└─ README.md             이 설명서
```
